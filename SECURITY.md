# Security Policy

## Supported Versions

Only the latest commit on `main` is supported with security fixes. No versioned
releases are published from this repository.

| Version | Supported |
| ------- | --------- |
| `main` (latest) | Yes |
| Older commits | No |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Use one of the following private reporting paths:

**Option 1 — GitHub private vulnerability reporting (preferred):**

1. Go to the [Security tab](../../security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the details and submit.

**Option 2 — Draft security advisory (fallback if the button above is unavailable):**

1. Go to **Security → Advisories** in this repository.
2. Click **New draft security advisory**.
3. Fill in the details and submit — this keeps the report private until
   a fix is ready.

A maintainer will acknowledge your report within 7 days and work with you on
a fix and coordinated disclosure timeline.
